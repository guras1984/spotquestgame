# Spot Quest Game · 다른 그림 탐험대

문제은행 기반 틀린 그림 찾기. 직접 그린 SVG 일러스트 30개 장면, 장면당 25개 변경 후보를 사용합니다. 10개 테마의 장면은 소품을 조합한 벡터 일러스트이며 사진이나 AI 생성 그림이 아닙니다.

- 쉬움: 차이 3개, 시간 무제한, 힌트 2회, 오답 시간 차감 없음
- 보통: 차이 5개, 120초, 힌트 2회, 오답 −5초
- 어려움: 차이 7개, 90초, 힌트 2회, 오답 −5초
- 지옥: 차이 15개, 45초, 힌트 없음, 오답 즉시 실패
- 같은 문제 재도전 / 새로운 문제 / 장면 선택 / 세션 내 무작위 장면 중복 방지
- 점 대신 나뭇잎·손잡이·꼬리·외곽선 등 물건의 모양을 교체합니다.
- 양쪽 그림의 물건 전체와 주변을 정답으로 인정합니다. 모바일에서는 약 22px 이상의 터치 여유를 보장합니다.
- 모바일 시작 화면 한 페이지, 플레이 화면 고정. 250% 확대 시 그림 안에서만 이동합니다.
- 화면 비율에 맞춰 배경과 소품을 배치하며 소품의 모양 비율은 유지합니다.
- 효과음, 자동 일시정지
- 랭킹, 계정, 브라우저 저장, 외부 분석 및 서버 통신은 없습니다. 새로고침하면 진행 상태가 초기화됩니다.

## 실행

이 폴더에서 `python3 -m http.server 8000` 후 http://localhost:8000 접속. ES 모듈이므로 HTML 파일 직접 열기는 지원하지 않습니다. 빌드나 외부 패키지는 필요 없습니다.

`node tests.mjs`로 장면별 문제 수, 정답 중복, 판정 영역 경계, 주변 터치 인정 및 빈 공간 오답, 지옥 규칙을 검사합니다.

## 파일

- `scenes.js`: 30개 장면 레시피, 벡터 그림, 차이 후보, 난이도
- `game.js`: 게임 진행, 타이머, 판정, 힌트, 확대, 결과
- `style.css`: PC/모바일 화면과 지옥 모드 색상
- `index.html`: 화면 구조

새 장면은 `scenes.js`의 recipes에 추가합니다. 실제 장면 수 표시는 화면에서도 함께 수정해야 합니다. 그림의 차이는 정해진 소품 부분에서만 발생하며 원본과 비교본의 배경 및 배치는 동일합니다.
